ClassHub 日常操作 Manual

日期：2026-08-16

本 manual 說明 ClassHub 0.2.0 的日常操作流程，對象包含管理者、教練、社團管理者，以及協助維運免費服務的管理人員。ClassHub 是 RWD 網頁服務，不是手機 App；聯絡人透過瀏覽器開啟聯絡人頁查看今日事項與圖片。

ClassHub 登入者在 UI 中稱為「使用者」。登入後主要分為兩個工作模式：

  • **群組模式**：正式群組聯絡簿流程，包含群組、成員、聯絡人綁定、今日事項、確認、回覆與收件狀態。
  • **臨時分享**：短期公開連結流程，以「群組」作為分享對象標籤，不需要建立成員與聯絡人綁定。知道分享連結的人可在有效期限內查看，公開頁每次開啟會讓閱讀紀錄加 1。

聯絡人邀請的手機操作細節請參考：

[`classhub-parent-invite-mobile-manual.md`](classhub-parent-invite-mobile-manual.md)

角色與前提

  • 使用者已取得 ClassHub ID 與密碼。
  • ClassHub 帳號已通過申請審核並啟用。
  • 使用者已使用瀏覽器登入 ClassHub。
  • 使用群組模式前，至少建立一個群組或社團。
  • 使用臨時分享前，至少建立一個分享群組。
  • 聯絡人端需先完成邀請綁定，才可查看對應成員的今日事項。
  • 臨時分享不需要聯絡人端綁定；知道連結的人即可查看。

服務邊界

  • ClassHub 是 Web-based / RWD 服務，不提供 App Store 或 Google Play App。
  • ClassHub 不提供手機系統層級推播。
  • LINE OA 是選配通知入口，完整內容仍以 ClassHub 聯絡人頁為準。
  • LINE OA 帳號、訊息額度、平台規則與相關費用不在 ClassHub 免費服務範圍內。
  • 系統會盡力即時顯示與傳遞訊息，但網路、裝置、第三方平台或系統狀況可能造成延遲。
  • ClassHub 不應作為緊急通知、即時救援或唯一正式通知管道。

免費帳號限制

目前免費帳號的主要限制如下：

  • 每個帳號最多 50 位成員。
  • 每位成員最多綁定 3 位聯絡人。
  • 每個帳號每天最多發布 30 則訊息。
  • 每則訊息最多附加 3 張圖片。
  • 每則臨時分享最多附加 3 張圖片，最長有效期限 3 天。
  • 名單匯入檔案必須是 CSV，單檔最大 256 KB，最多 300 筆資料列。
  • 管理者上傳圖片預設保留 24 小時。
  • API、Webhook、選配通知投遞會受頻率與重試限制。

服務時間：

  • ClassHub 免費服務每日預定開放時間為台灣時間 06:00-22:00。
  • 非服務時間內，系統可能暫停、進行維護、備份或資源調整。
  • 非服務時間內不保證可登入、發布、查看訊息或接收通知。
  • ClassHub 不應作為緊急通知、即時救援或唯一正式通知管道。

帳號期限與未登入處理：

  • 每個免費帳號最多使用 6 個月。
  • 連續 30 天未登入時，系統會盡力寄送 Email 通知。
  • 通知後 10 天內仍未登入者，帳號將被停用。
  • 帳號停用後 5 天內若未提出恢復申請或完成必要確認，帳號與相關資料可能被移除。
  • 期滿後可重新申請，但舊資料不移轉。

使用者日常操作流程

1. 登入

  • 開啟 ClassHub 網頁。
  • 輸入 ClassHub ID 與密碼。
  • 按「登入」。

登入後頁面會顯示使用者狀態，並可切換「群組模式」、「臨時分享」與「回饋」。

2. 選擇工作模式

登入後先選擇要使用的模式：

  • **群組模式**：用於聯絡簿、成員 / 聯絡人名單、聯絡人邀請、今日事項與收件狀態。
  • **臨時分享**：用於不需要成員 / 聯絡人綁定的臨時分享，例如體驗課、活動通知、臨時群組公告。

聯絡人頁不是登入者的主工作模式。聯絡人通常透過邀請連結進入，或由已綁定的聯絡人 session 直接開啟。

若系統要求更改密碼：

  • 在「更改密碼」區塊輸入新密碼。
  • 再次輸入確認密碼。
  • 按「更新密碼」。
  • 更新後重新登入。

3. 群組模式：選定或建立群組

在「群組」區塊：

  • 從「選定群組」選擇既有群組。
  • 若尚未建立群組，輸入群組名稱後建立。
  • 發布、聯絡人邀請、成員管理會以目前選定群組為主要操作範圍。
  • 若群組已不再使用，可按「刪除群組」先查看影響摘要。

操作建議：

  • 群組名稱用管理者或聯絡人都看得懂的稱呼。
  • 若是社團，可使用「週三羽球初階班」、「週六美術 A 班」這類名稱。
  • 不需要在群組名稱放入成員個資。
  • 刪除群組前，請先確認該班今日事項、成員與聯絡人綁定是否已不再需要。

4. 群組模式：匯入群組名單

ClassHub 第一版採用「匯入式同步」，不是即時雙向 Google Sheet 同步。使用者先在 Google Sheet 整理名單，再匯出 CSV 檔案，回到 ClassHub 上傳與同步。

CSV 欄位建議如下：

  • 群組名稱，必填。
  • 成員姓名，必填。
  • 聯絡人稱呼，選填。
  • 聯絡人電話，選填。
  • 成員編號，選填。

匯入流程：

  • 在 Google Sheet 整理群組、成員與聯絡人名單。
  • 匯出 CSV 檔案。
  • 在 ClassHub「Google Sheet 匯入」區塊按「選擇 CSV」。
  • 按「預覽」檢查群組新增、成員新增、成員更新、成員停用、聯絡人新增與聯絡人停用數量。
  • 若有格式錯誤，可下載錯誤清單修正後重新預覽。
  • 確認預覽結果後，按「同步名單」。

匯入限制：

  • CSV 單檔最大 256 KB。
  • CSV 單檔最多 300 筆資料列。
  • 正式帳號有效成員總數仍受 50 位上限限制。
  • CSV 中未出現、但同一匯入群組中已存在的成員或聯絡人，會被標記為停用，不會直接刪除。

5. 群組模式：建立成員與聯絡人邀請

在「連結與邀請」區塊建立聯絡人邀請：

  • 選擇群組。
  • 若是新成員，選「新增成員」並輸入成員稱呼。
  • 若是既有成員，直接選擇該成員。
  • 輸入聯絡人稱呼。
  • 聯絡人電話為選填，非必要不建議收集。
  • 按「建立聯絡人並產生邀請碼」。

系統會產生：

  • 聯絡人邀請 QR Code。
  • 聯絡人邀請連結。
  • 分享按鈕。
  • 複製連結按鈕。

使用者可以請聯絡人掃 QR Code，或用手機分享連結給聯絡人。完整邀請流程請參考 parent invite manual。

若群組內已有成員與聯絡人連結，使用者也可以按「產生整班 QR Code」。系統會產生每位聯絡人的邀請卡片，包含成員、聯絡人、邀請連結與 QR Code；使用者可直接列印 QR Code 卡片。

6. 群組模式：發布今日事項

在「快速發布」區塊：

  • 確認已選定群組。
  • 輸入標題。
  • 選擇分類，例如公告、作業、攜帶物品、活動、請假、繳費提醒或其他。
  • 輸入內容。
  • 視需要勾選「需要確認」。
  • 視需要上傳圖片，最多 3 張。
  • 按「發布」。

發布後：

  • 今日事項會出現在使用者的「群組聯絡簿」。
  • 已綁定的聯絡人可在聯絡人頁看到對應事項。
  • 需要確認的事項，聯絡人可以按「確認」。
  • 聯絡人可在事項下方輸入最多 200 字的簡短回覆。
  • 使用者端可看到已讀、已確認數量與聯絡人回覆內容。

發布前檢查：

  • 是否選到正確群組。
  • 標題是否清楚。
  • 是否避免放入過多個資。
  • 圖片是否只包含必要資訊。
  • 是否不把 ClassHub 當緊急通知管道。

7. 群組模式：查看今日貼文與確認狀態

在「群組聯絡簿」區塊，使用者可查看：

  • 今日已發布事項。
  • 分類、標題與內容。
  • 圖片是否可正常顯示。
  • 收件人數。
  • 已讀數。
  • 已確認數。
  • 回覆數與聯絡人回覆內容。

若需要確認每位收件人的狀態，按貼文上的「查看狀態」。系統會顯示收件人明細：

  • 成員姓名與聯絡人稱呼。
  • 已查看或尚未查看。
  • 已確認、尚未確認或不需確認。
  • 回覆數。
  • 最後查看、確認與回覆時間。
  • 最新一則回覆內容。

狀態面板可按「重新載入」取得最新狀態。

若發現內容錯誤，應刪除原貼文後重新發布；目前已發布貼文以刪除與重發為主要修正方式。

8. 群組模式：刪除貼文

使用者可在「群組聯絡簿」區塊刪除貼文：

  • 刪除單則貼文：按該貼文的「刪除」。
  • 批次刪除：勾選多則貼文後按「刪除選取」。
  • 系統會要求確認後才刪除。

刪除後貼文會從今日顯示中移除。圖片仍會依到期與清理程序處理。

9. 群組模式：刪除群組

若整個群組或社團已結束，使用者可在「群組」區塊刪除目前選定的群組。

刪除流程：

  • 先選定要刪除的群組。
  • 按「刪除群組」。
  • 系統會載入刪除摘要，列出受影響成員、聯絡人綁定，以及會封存或保留的聯絡人。
  • 確認摘要後，輸入完整群組名稱。
  • 按「確認刪除群組」。

刪除後的處理：

  • 該群組會被封存。
  • 該群組內的成員會被封存。
  • 該班成員與聯絡人的綁定會被移除。
  • 未使用的相關聯絡人邀請會到期。
  • 若某位聯絡人刪除該班成員後沒有其他成員，該聯絡人會被封存，登入 session 也會被撤銷。
  • 若某位聯絡人仍綁定其他群組或其他成員，該聯絡人會保留。

注意事項：

  • 刪除群組是危險操作，適合用於群組或活動已結束、不再需要使用的情境。
  • 若只是群組名稱打錯，請建立正確群組並調整資料，不要用刪除群組取代一般修正流程。
  • 刪除群組會影響聯絡人頁可查看的內容與登入狀態；操作前請確認聯絡人不再需要該班資料。

10. 群組模式：管理成員與聯絡人

在「成員與聯絡人」區塊：

成員可操作：

  • 更新成員稱呼。
  • 調整成員所屬群組。
  • 刪除成員。

聯絡人可操作：

  • 更新聯絡人稱呼。
  • 更新聯絡人電話。
  • 刪除聯絡人。

注意事項：

  • 刪除成員或聯絡人會影響聯絡人頁可查看的內容與綁定關係。
  • 若只是名稱打錯，優先使用更新，不要刪除重建。
  • 成員與聯絡人資料應使用稱呼、代號或暱稱；能不收集真實姓名就不收集。

臨時分享流程

臨時分享用於跳脫群組 / 成員 / 聯絡人綁定的臨時公開分享。它適合臨時活動、體驗課、社團公告、課前提醒或任何不需要建立正式聯絡人帳號的情境。

1. 建立或選定分享群組

在「臨時分享」中：

  • 輸入群組名稱，例如「體驗課聯絡人」、「週末活動」、「新生說明會」。
  • 按「建立群組」。
  • 從「分享群組」選單選定要使用的群組。

群組只是分享對象標籤，不代表成員名單或聯絡人綁定。移除群組會讓該群組不再出現在選單中；已建立的分享仍保留歷史群組名稱與停用 / 到期狀態。

2. 建立臨時分享

在已選定群組後：

  • 輸入標題。
  • 輸入分享內容。
  • 選擇有效期限：1 天、2 天或 3 天。
  • 視需要上傳圖片，最多 3 張。
  • 按「建立臨時分享」。

系統會產生：

  • 公開分享連結。
  • QR Code。
  • 複製連結按鈕。
  • 系統分享按鈕。
  • 停用按鈕。

臨時分享公開頁不需要登入、不需要 ClassHub ID，也不需要聯絡人綁定。知道連結的人可在有效期限內查看。

3. 查看與停用臨時分享

臨時分享會列出已建立的臨時分享，包含：

  • 分享群組。
  • 標題。
  • 到期時間。
  • 狀態。
  • 閱讀次數。

公開頁每次被開啟時，閱讀次數會加 1。若分享不應繼續被查看，使用者可按「停用」。

聯絡人日常操作流程

1. 完成綁定

聯絡人收到使用者提供的 QR Code 或邀請連結後：

  • 用手機瀏覽器開啟連結，或用相機掃 QR Code。
  • ClassHub 聯絡人頁會帶入 ClassHub ID 與邀請碼。
  • 按「綁定聯絡人」。
  • 綁定完成後即可查看今日事項。

2. 查看今日事項

在聯絡人頁：

  • 查看「家庭摘要」。
  • 查看「聯絡人今日事項」。
  • 開啟圖片或附件內容。
  • 若事項要求確認，按「確認」。
  • 需要回覆管理者時，在事項下方輸入簡短回覆並按「送出回覆」。
  • 可使用「重新整理」取得最新內容。

3. 查看通知

聯絡人可在「通知」區塊查看收件匣：

  • 未讀通知會顯示未讀狀態。
  • 可按「標示已讀」。
  • 通知只是提示入口，完整內容仍以今日事項為準。

圖片與資料保留

圖片處理原則：

  • 圖片透過使用者端上傳。
  • 系統會重新編碼為 JPEG，移除原始 EXIF metadata。
  • 圖片不提供公開原始附件網址。
  • 前端取得的是受 API 權限控管的圖片路徑。
  • 聯絡人只能查看自己綁定成員可讀的圖片。
  • 圖片預設 24 小時後到期。
  • 到期圖片會停止顯示，並由背景或管理操作清理。

操作建議：

  • 不要上傳含敏感個資的圖片。
  • 不要把 ClassHub 當作長期圖片儲存或圖床。
  • 重要資料請自行備份。

管理與維運操作

1. 工作面板

使用者或管理者可進入「管理」頁籤查看工作面板：

  • 清理圖片。
  • 重送同步。
  • 重送選配通知。
  • 載入同步紀錄。
  • 載入選配通知狀態。

日常建議：

  • 若圖片到期但仍占用空間，可執行「清理圖片」。
  • 若外部同步暫時失敗，可執行「重送同步」。
  • 若 LINE OA 選配通知暫時失敗，可執行「重送選配通知」。
  • 若投遞紀錄異常增加，應檢查 webhook 或第三方平台是否不穩定。

2. LINE OA 選配通知

LINE OA 是可選通知方式，只用來提示聯絡人有新訊息。完整聯絡簿、附件、歷史紀錄與確認狀態仍在 ClassHub 聯絡人頁。

設定時：

  • 在「LINE OA（Optional）」區塊輸入 Channel Access Token。
  • 輸入 Channel Secret。
  • 按「儲存選配通知設定」。
  • 載入選配通知狀態確認是否已設定。

注意事項：

  • LINE 官方帳號、訊息額度與費用由使用者自行承擔。
  • LINE 平台延遲或政策變更不屬於 ClassHub 保證範圍。
  • 不應承諾 LINE 訊息一定即時送達。

3. 回饋與問題回報

在「回饋」區塊可送出問題或建議：

  • 確認 ClassHub ID。
  • 輸入姓名或稱呼。
  • 選擇分類。
  • 輸入 Email。
  • 描述問題或建議。
  • 送出。

免費服務支援範圍：

  • 操作文件。
  • 問題回報表單。
  • 重要錯誤修復。
  • 必要的安全與穩定性改善。

免費服務不提供：

  • 電話客服。
  • 即時客服。
  • 承諾回覆時間。
  • 資料代為輸入、整理或匯入。
  • 個別客製化功能。
  • 因服務中斷、延遲或資料遺失所產生的補償。

帳號申請與審核操作

免費帳號採申請審核制，不開放完全公開即時註冊。

申請審核時，建議確認：

  • 申請人 Email 是否可聯絡。
  • 使用場景是否符合群組、社團、教練或教學溝通。
  • 申請內容是否疑似垃圾註冊、廣告、濫用或不當用途。
  • 申請人是否接受免費服務限制、非 SLA、非緊急通知與資料自備份原則。

不建議在申請階段收集：

  • 成員名單。
  • 聯絡人名單。
  • 聯絡人電話。
  • 詳細地址。
  • 身分證明文件。
  • 預計群組數。
  • 預計成員或聯絡人數。
  • LINE OA 使用需求。

審核後若開通帳號，應記錄：

  • ClassHub ID。
  • 帳號啟用日期。
  • 帳號到期日期。
  • 申請 Email。
  • 審核狀態。
  • 必要的管理備註。

安全與濫用處理

需留意下列風險：

  • 垃圾帳號大量申請。
  • 機器人上傳圖片。
  • 把 ClassHub 當免費圖床。
  • 大量呼叫 API 或 Webhook。
  • 發送廣告或不當內容。
  • 猜測群組碼、邀請碼或聯絡人登入連結。
  • 惡意建立大量群組、成員或聯絡人資料消耗資源。

最低限度應維持：

  • 申請與登入頻率限制。
  • IP 與帳號 rate limit。
  • 圖片格式與大小驗證。
  • Webhook 簽章驗證。
  • 短效且不可預測的登入 token。
  • 管理者停權與刪除能力。
  • 異常流量告警。
  • 禁止公開存取原始附件網址。

若發現濫用：

  • 先停用可疑帳號或限制操作。
  • 檢查近期貼文、圖片、Webhook 與登入紀錄。
  • 清理不當內容與過期附件。
  • 視情況封鎖來源 IP 或調整 rate limit。
  • 記錄處理結果。

上線前檢查清單

帳號與限制：

  • 已確認帳號採申請審核制。
  • 已確認免費帳號期限與未登入處理規則。
  • 已確認 50 位成員、每位成員 3 位聯絡人、每日 30 則訊息限制。

核心流程：

  • 管理者可登入。
  • 管理者可建立群組。
  • 管理者可建立聯絡人邀請。
  • 聯絡人可綁定邀請。
  • 管理者可發布今日事項。
  • 聯絡人可查看今日事項。
  • 聯絡人可確認需要確認的事項。
  • 管理者可看到已讀與已確認數。

資料與安全：

  • 圖片只能透過授權 API 讀取。
  • 圖片到期後不可顯示。
  • 圖片清理可手動執行。
  • 日誌與 analytics 不記錄完整 token、成員姓名、聯絡人姓名、訊息內容或圖片內容。
  • Webhook payload 不包含聯絡簿內容或個人資料。

服務聲明：

  • 已說明不保證永久營運。
  • 已說明不保證 100% 可用。
  • 已說明不可作為緊急通知管道。
  • 已提醒重要資料自行備份。
  • 已保留暫停帳號、刪除違規內容與終止服務的權利。

常見問題

聯絡人說沒有收到通知

ClassHub 不是 App，不提供手機系統推播。請先請聯絡人打開 ClassHub 聯絡人頁並按重新整理。若使用 LINE OA，LINE 只作為選配通知入口，可能因 LINE 平台、網路或設定造成延遲。

聯絡人看不到今日事項

檢查：

  • 聯絡人是否已完成綁定。
  • 管理者是否發布到正確群組。
  • 成員是否仍為 active。
  • 聯絡人是否綁定到該成員。
  • 聯絡人頁是否使用正確 ClassHub ID。

圖片看不到

檢查：

  • 圖片是否已超過保留時間。
  • 聯絡人是否有該成員的存取權。
  • 圖片是否上傳成功。
  • 管理者或管理者是否已執行清理圖片。

今日發布失敗

檢查：

  • 是否已選群組。
  • 今日發布數是否已達 30 則。
  • 是否已有成員與聯絡人綁定。
  • 圖片是否超過張數或大小限制。
  • 網路或後端服務是否正常。

帳號到期後可以恢復資料嗎

不保證。免費帳號期滿後可以重新申請，但舊帳號資料不移轉。重要資料應由使用者自行備份。
