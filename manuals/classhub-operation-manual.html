ClassHub 日常操作 Manual

日期：2026-08-12

本 manual 說明老師、教練、社團管理者與服務管理人員的日常操作。ClassHub 是 RWD 網頁服務，不是手機 App；家長透過瀏覽器開啟家長頁查看今日事項與圖片。

家長邀請手機流程請參考 classhub-parent-invite-mobile-manual.html 或 classhub-parent-invite-mobile-manual.md。

角色與前提

  • 管理者或老師已取得 ClassHub ID 與密碼。
  • ClassHub 帳號已通過申請審核並啟用。
  • 老師已使用瀏覽器登入 ClassHub。
  • 至少建立一個班級或社團。
  • 家長端需先完成邀請綁定，才可查看對應學生的今日事項。

服務邊界

ClassHub 不是 App，不提供手機系統推播；LINE OA 是選配通知入口，完整內容仍以 ClassHub 家長頁為準。ClassHub 不應作為緊急通知、即時救援或唯一正式通知管道。
  • 系統會盡力即時顯示與傳遞訊息，但網路、裝置、第三方平台或系統狀況可能造成延遲。
  • LINE 官方帳號、訊息額度、平台規則與相關費用不在 ClassHub 免費服務範圍內。
  • 重要資料應由使用者自行備份。

免費帳號限制

每個帳號最多 50 位學生。
每位學生最多綁定 3 位家長。
每個帳號每天最多發布 30 則訊息。
每則訊息最多附加 3 張圖片。
名單匯入檔案必須是 CSV，單檔最大 256 KB，最多 300 筆資料列。
教師上傳圖片預設保留 24 小時。
每日預定服務時間為台灣時間 06:00-22:00。
帳號最多使用 6 個月，期滿後可重新申請但資料不移轉。

非服務時間內，系統可能暫停、進行維護、備份或資源調整，不保證可登入、發布、查看訊息或接收通知。

老師日常操作流程

1. 登入

  1. 開啟 ClassHub 網頁。
  2. 輸入 ClassHub ID 與密碼。
  3. 按「登入」。

若系統要求更改密碼，請在「更改密碼」區塊輸入新密碼並更新，完成後重新登入。

2. 選定或建立班級

  1. 從「選定班級」選擇既有班級。
  2. 若尚未建立班級，輸入班級名稱後建立。
  3. 發布、家長邀請與學生管理會以目前選定班級為主要操作範圍。
  4. 若班級已不再使用，可按「刪除班級」先查看影響摘要。

刪除班級前，請先確認該班今日事項、學生與家長綁定是否已不再需要。

3. 匯入班級名單

ClassHub 第一版採用「匯入式同步」，不是即時雙向 Google Sheet 同步。老師先在 Google Sheet 整理名單，再匯出 CSV 檔案，回到 ClassHub 上傳與同步。

  • 建議欄位：班級名稱、學生姓名、家長稱呼、家長電話、學生編號。
  • 班級名稱與學生姓名為必填；家長稱呼、家長電話與學生編號為選填。
  • CSV 單檔最大 256 KB，最多 300 筆資料列。
  • 正式帳號有效學生總數仍受 50 位上限限制。
  1. 在 Google Sheet 整理班級、學生與家長名單。
  2. 匯出 CSV 檔案。
  3. 在 ClassHub「Google Sheet 匯入」區塊按「選擇 CSV」。
  4. 按「預覽」檢查新增、更新、停用與錯誤數量。
  5. 若有格式錯誤，可下載錯誤清單修正後重新預覽。
  6. 確認預覽結果後，按「同步名單」。

4. 建立學生與家長邀請

  1. 選擇班級。
  2. 新學生選「新增學生」並輸入學生稱呼；既有學生直接選擇該學生。
  3. 輸入家長稱呼，家長電話非必要不建議收集。
  4. 按「建立家長並產生邀請碼」。
  5. 用 QR Code、分享按鈕或複製連結交給家長。

若班級內已有學生與家長連結，老師也可以按「產生整班 QR Code」。系統會產生每位家長的邀請卡片，包含學生、家長、邀請連結與 QR Code；老師可直接列印 QR Code 卡片。

5. 發布今日事項

  1. 確認已選定班級。
  2. 輸入標題、分類與內容。
  3. 視需要勾選「需要確認」。
  4. 視需要上傳圖片，最多 3 張。
  5. 按「發布」。

發布後，家長可在家長頁看到對應事項；需要確認的事項可按「確認」；家長也可送出最多 200 字的簡短回覆。老師端可查看已讀、已確認數量與家長回覆內容。

6. 查看今日貼文與確認狀態

  • 在「教師今日貼文」查看分類、標題、內容、圖片、收件人數、已讀數、確認數與回覆數。
  • 按「查看狀態」可開啟逐位收件人明細。
  • 明細包含學生、家長、已查看或尚未查看、已確認或尚未確認、回覆數、最後查看/確認/回覆時間與最新回覆內容。
  • 狀態面板可按「重新載入」取得最新狀態。

7. 刪除貼文

  • 若內容錯誤，刪除原貼文後重新發布。
  • 可刪除單則貼文，也可勾選多則後按「刪除選取」。

8. 刪除班級

若整個班級或社團已結束，老師可在「班級」區塊刪除目前選定的班級。

  1. 先選定要刪除的班級。
  2. 按「刪除班級」。
  3. 系統會載入刪除摘要，列出受影響學生、家長綁定，以及會封存或保留的家長。
  4. 確認摘要後，輸入完整班級名稱。
  5. 按「確認刪除班級」。
  • 該班級會被封存。
  • 該班級內的學生會被封存。
  • 該班學生與家長的綁定會被移除。
  • 未使用的相關家長邀請會到期。
  • 若某位家長刪除該班學生後沒有其他學生，該家長會被封存，登入 session 也會被撤銷。
  • 若某位家長仍綁定其他班級或其他學生，該家長會保留。

刪除班級是危險操作，適合用於班級或活動已結束、不再需要使用的情境。若只是班級名稱打錯，請建立正確班級並調整資料，不要用刪除班級取代一般修正流程。

9. 管理學生與家長

  • 學生可更新稱呼、調整班級或刪除。
  • 家長可更新稱呼、更新電話或刪除。
  • 若只是名稱打錯，優先更新，不要刪除重建。
  • 能使用稱呼、代號或暱稱時，不要求真實姓名。

家長日常操作流程

  1. 收到老師提供的 QR Code 或邀請連結。
  2. 用手機瀏覽器開啟或掃 QR Code。
  3. 按「綁定家長」。
  4. 查看「家庭摘要」與「家長今日事項」。
  5. 若事項要求確認，按「確認」。
  6. 需要回覆老師時，在事項下方輸入簡短回覆並按「送出回覆」。
  7. 在「通知」查看未讀通知並標示已讀。

圖片與資料保留

  • 圖片會重新編碼為 JPEG，移除原始 EXIF metadata。
  • 圖片不提供公開原始附件網址。
  • 前端取得的是受 API 權限控管的圖片路徑。
  • 家長只能查看自己綁定學生可讀的圖片。
  • 圖片預設 24 小時後到期，到期後停止顯示並由清理程序刪除。

管理與維運操作

  • 「清理圖片」：清除已到期圖片。
  • 「重送同步」：重送暫時失敗的同步投遞。
  • 「重送選配通知」：重送暫時失敗的 LINE OA 選配通知。
  • 「載入紀錄」：查看同步紀錄。
  • 「載入選配通知」：查看 LINE OA 設定與投遞狀態。

帳號申請與審核操作

  • 確認申請人 Email 是否可聯絡。
  • 確認使用場景是否符合班級、社團、教練或教學溝通。
  • 確認申請內容是否疑似垃圾註冊、廣告、濫用或不當用途。
  • 不要在申請階段收集學生名單、家長名單、家長電話、詳細地址、身分證明文件、預計班級數、預計學生或家長數、LINE OA 使用需求。

常見問題

家長說沒有收到通知

ClassHub 不是 App，不提供手機系統推播。請先請家長打開 ClassHub 家長頁並按重新整理。若使用 LINE OA，LINE 只作為選配通知入口，可能因平台、網路或設定造成延遲。

家長看不到今日事項

檢查家長是否已完成綁定、老師是否發布到正確班級、學生是否仍為 active、家長是否綁定到該學生，以及家長頁是否使用正確 ClassHub ID。

圖片看不到

檢查圖片是否已超過保留時間、家長是否有該學生的存取權、圖片是否上傳成功，以及是否已執行清理圖片。

今日發布失敗

檢查是否已選班級、今日發布數是否已達 30 則、是否已有學生與家長綁定、圖片是否超過張數或大小限制，以及後端服務是否正常。
