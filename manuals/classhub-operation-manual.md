# ClassHub 日常操作 Manual

日期：2026-08-07

本 manual 說明 ClassHub 的日常操作流程，對象包含老師、教練、社團管理者，以及協助維運免費服務的管理人員。ClassHub 是 RWD 網頁服務，不是手機 App；家長透過瀏覽器開啟家長頁查看今日事項與圖片。

家長邀請的手機操作細節請參考：

[`classhub-parent-invite-mobile-manual.md`](classhub-parent-invite-mobile-manual.md)

## 角色與前提

- 管理者或老師已取得 ClassHub ID 與密碼。
- ClassHub 帳號已通過申請審核並啟用。
- 老師已使用瀏覽器登入 ClassHub。
- 至少建立一個班級或社團。
- 家長端需先完成邀請綁定，才可查看對應學生的今日事項。

## 服務邊界

- ClassHub 是 Web-based / RWD 服務，不提供 App Store 或 Google Play App。
- ClassHub 不提供手機系統層級推播。
- LINE OA 是選配通知入口，完整內容仍以 ClassHub 家長頁為準。
- LINE OA 帳號、訊息額度、平台規則與相關費用不在 ClassHub 免費服務範圍內。
- 系統會盡力即時顯示與傳遞訊息，但網路、裝置、第三方平台或系統狀況可能造成延遲。
- ClassHub 不應作為緊急通知、即時救援或唯一正式通知管道。

## 免費帳號限制

目前免費帳號的主要限制如下：

- 每個帳號最多 50 位學生。
- 每位學生最多綁定 3 位家長。
- 每個帳號每天最多發布 30 則訊息。
- 每則訊息最多附加 3 張圖片。
- 名單匯入檔案必須是 CSV，單檔最大 256 KB，最多 300 筆資料列。
- 教師上傳圖片預設保留 24 小時。
- API、Webhook、選配通知投遞會受頻率與重試限制。

服務時間：

- ClassHub 免費服務每日預定開放時間為台灣時間 06:00-22:00。
- 非服務時間內，系統可能暫停、進行維護、備份或資源調整。
- 非服務時間內不保證可登入、發布、查看訊息或接收通知。
- ClassHub 不應作為緊急通知、即時救援或唯一正式通知管道。

帳號期限與未登入處理：

- 每個免費帳號最多使用 6 個月。
- 連續 30 天未登入時，系統會盡力寄送 Email 通知。
- 通知後 10 天內仍未登入者，帳號將被停用。
- 帳號停用後 5 天內若未提出恢復申請或完成必要確認，帳號與相關資料可能被移除。
- 期滿後可重新申請，但舊資料不移轉。

## 老師日常操作流程

### 1. 登入

1. 開啟 ClassHub 網頁。
2. 輸入 ClassHub ID 與密碼。
3. 按「登入」。

登入後頁面會顯示老師狀態、班級狀態與今日貼文。

若系統要求更改密碼：

1. 在「更改密碼」區塊輸入新密碼。
2. 再次輸入確認密碼。
3. 按「更新密碼」。
4. 更新後重新登入。

### 2. 選定或建立班級

在「班級」區塊：

1. 從「選定班級」選擇既有班級。
2. 若尚未建立班級，輸入班級名稱後建立。
3. 發布、家長邀請、學生管理會以目前選定班級為主要操作範圍。

操作建議：

- 班級名稱用老師或家長都看得懂的稱呼。
- 若是社團，可使用「週三羽球初階班」、「週六美術 A 班」這類名稱。
- 不需要在班級名稱放入學生個資。

### 3. 匯入班級名單

ClassHub 第一版採用「匯入式同步」，不是即時雙向 Google Sheet 同步。老師先在 Google Sheet 整理名單，再匯出 CSV 檔案，回到 ClassHub 上傳與同步。

CSV 欄位建議如下：

- 班級名稱，必填。
- 學生姓名，必填。
- 家長稱呼，選填。
- 家長電話，選填。
- 學生編號，選填。

匯入流程：

1. 在 Google Sheet 整理班級、學生與家長名單。
2. 匯出 CSV 檔案。
3. 在 ClassHub「Google Sheet 匯入」區塊按「選擇 CSV」。
4. 按「預覽」檢查班級新增、學生新增、學生更新、學生停用、家長新增與家長停用數量。
5. 若有格式錯誤，可下載錯誤清單修正後重新預覽。
6. 確認預覽結果後，按「同步名單」。

匯入限制：

- CSV 單檔最大 256 KB。
- CSV 單檔最多 300 筆資料列。
- 正式帳號有效學生總數仍受 50 位上限限制。
- CSV 中未出現、但同一匯入班級中已存在的學生或家長，會被標記為停用，不會直接刪除。

### 4. 建立學生與家長邀請

在「連結與邀請」區塊建立家長邀請：

1. 選擇班級。
2. 若是新學生，選「新增學生」並輸入學生稱呼。
3. 若是既有學生，直接選擇該學生。
4. 輸入家長稱呼。
5. 家長電話為選填，非必要不建議收集。
6. 按「建立家長並產生邀請碼」。

系統會產生：

- 家長邀請 QR Code。
- 家長邀請連結。
- 分享按鈕。
- 複製連結按鈕。

老師可以請家長掃 QR Code，或用手機分享連結給家長。完整邀請流程請參考 parent invite manual。

若班級內已有學生與家長連結，老師也可以按「產生整班 QR Code」。系統會產生每位家長的邀請卡片，包含學生、家長、邀請連結與 QR Code；老師可直接列印 QR Code 卡片。

### 5. 發布今日事項

在「快速發布」區塊：

1. 確認已選定班級。
2. 輸入標題。
3. 選擇分類，例如公告、作業、攜帶物品、活動、請假、繳費提醒或其他。
4. 輸入內容。
5. 視需要勾選「需要確認」。
6. 視需要上傳圖片，最多 3 張。
7. 按「發布」。

發布後：

- 今日事項會出現在老師的「教師今日貼文」。
- 已綁定的家長可在家長頁看到對應事項。
- 需要確認的事項，家長可以按「確認」。
- 家長可在事項下方輸入最多 200 字的簡短回覆。
- 老師端可看到已讀、已確認數量與家長回覆內容。

發布前檢查：

- 是否選到正確班級。
- 標題是否清楚。
- 是否避免放入過多個資。
- 圖片是否只包含必要資訊。
- 是否不把 ClassHub 當緊急通知管道。

### 6. 查看今日貼文與確認狀態

在「教師今日貼文」區塊，老師可查看：

- 今日已發布事項。
- 分類、標題與內容。
- 圖片是否可正常顯示。
- 收件人數。
- 已讀數。
- 已確認數。
- 回覆數與家長回覆內容。

若需要確認每位收件人的狀態，按貼文上的「查看狀態」。系統會顯示收件人明細：

- 學生姓名與家長稱呼。
- 已查看或尚未查看。
- 已確認、尚未確認或不需確認。
- 回覆數。
- 最後查看、確認與回覆時間。
- 最新一則回覆內容。

狀態面板可按「重新載入」取得最新狀態。

若發現內容錯誤，應刪除原貼文後重新發布；目前已發布貼文以刪除與重發為主要修正方式。

### 7. 刪除貼文

老師可在「教師今日貼文」區塊刪除貼文：

1. 刪除單則貼文：按該貼文的「刪除」。
2. 批次刪除：勾選多則貼文後按「刪除選取」。
3. 系統會要求確認後才刪除。

刪除後貼文會從今日顯示中移除。圖片仍會依到期與清理程序處理。

### 8. 管理學生與家長

在「學生與家長」區塊：

學生可操作：

- 更新學生稱呼。
- 調整學生所屬班級。
- 刪除學生。

家長可操作：

- 更新家長稱呼。
- 更新家長電話。
- 刪除家長。

注意事項：

- 刪除學生或家長會影響家長頁可查看的內容與綁定關係。
- 若只是名稱打錯，優先使用更新，不要刪除重建。
- 學生與家長資料應使用稱呼、代號或暱稱；能不收集真實姓名就不收集。

## 家長日常操作流程

### 1. 完成綁定

家長收到老師提供的 QR Code 或邀請連結後：

1. 用手機瀏覽器開啟連結，或用相機掃 QR Code。
2. ClassHub 家長頁會帶入 ClassHub ID 與邀請碼。
3. 按「綁定家長」。
4. 綁定完成後即可查看今日事項。

### 2. 查看今日事項

在家長頁：

1. 查看「家庭摘要」。
2. 查看「家長今日事項」。
3. 開啟圖片或附件內容。
4. 若事項要求確認，按「確認」。
5. 需要回覆老師時，在事項下方輸入簡短回覆並按「送出回覆」。
6. 可使用「重新整理」取得最新內容。

### 3. 查看通知

家長可在「通知」區塊查看收件匣：

- 未讀通知會顯示未讀狀態。
- 可按「標示已讀」。
- 通知只是提示入口，完整內容仍以今日事項為準。

## 圖片與資料保留

圖片處理原則：

- 圖片透過老師端上傳。
- 系統會重新編碼為 JPEG，移除原始 EXIF metadata。
- 圖片不提供公開原始附件網址。
- 前端取得的是受 API 權限控管的圖片路徑。
- 家長只能查看自己綁定學生可讀的圖片。
- 圖片預設 24 小時後到期。
- 到期圖片會停止顯示，並由背景或管理操作清理。

操作建議：

- 不要上傳含敏感個資的圖片。
- 不要把 ClassHub 當作長期圖片儲存或圖床。
- 重要資料請自行備份。

## 管理與維運操作

### 1. 工作面板

老師或管理者可進入「管理」頁籤查看工作面板：

- 清理圖片。
- 重送同步。
- 重送選配通知。
- 載入同步紀錄。
- 載入選配通知狀態。

日常建議：

- 若圖片到期但仍占用空間，可執行「清理圖片」。
- 若外部同步暫時失敗，可執行「重送同步」。
- 若 LINE OA 選配通知暫時失敗，可執行「重送選配通知」。
- 若投遞紀錄異常增加，應檢查 webhook 或第三方平台是否不穩定。

### 2. LINE OA 選配通知

LINE OA 是可選通知方式，只用來提示家長有新訊息。完整聯絡簿、附件、歷史紀錄與確認狀態仍在 ClassHub 家長頁。

設定時：

1. 在「LINE OA（Optional）」區塊輸入 Channel Access Token。
2. 輸入 Channel Secret。
3. 按「儲存選配通知設定」。
4. 載入選配通知狀態確認是否已設定。

注意事項：

- LINE 官方帳號、訊息額度與費用由使用者自行承擔。
- LINE 平台延遲或政策變更不屬於 ClassHub 保證範圍。
- 不應承諾 LINE 訊息一定即時送達。

### 3. 回饋與問題回報

在「回饋」區塊可送出問題或建議：

1. 確認 ClassHub ID。
2. 輸入姓名或稱呼。
3. 選擇分類。
4. 輸入 Email。
5. 描述問題或建議。
6. 送出。

免費服務支援範圍：

- 操作文件。
- 問題回報表單。
- 重要錯誤修復。
- 必要的安全與穩定性改善。

免費服務不提供：

- 電話客服。
- 即時客服。
- 承諾回覆時間。
- 資料代為輸入、整理或匯入。
- 個別客製化功能。
- 因服務中斷、延遲或資料遺失所產生的補償。

## 帳號申請與審核操作

免費帳號採申請審核制，不開放完全公開即時註冊。

申請審核時，建議確認：

- 申請人 Email 是否可聯絡。
- 使用場景是否符合班級、社團、教練或教學溝通。
- 申請內容是否疑似垃圾註冊、廣告、濫用或不當用途。
- 申請人是否接受免費服務限制、非 SLA、非緊急通知與資料自備份原則。

不建議在申請階段收集：

- 學生名單。
- 家長名單。
- 家長電話。
- 詳細地址。
- 身分證明文件。
- 預計班級數。
- 預計學生或家長數。
- LINE OA 使用需求。

審核後若開通帳號，應記錄：

- ClassHub ID。
- 帳號啟用日期。
- 帳號到期日期。
- 申請 Email。
- 審核狀態。
- 必要的管理備註。

## 安全與濫用處理

需留意下列風險：

- 垃圾帳號大量申請。
- 機器人上傳圖片。
- 把 ClassHub 當免費圖床。
- 大量呼叫 API 或 Webhook。
- 發送廣告或不當內容。
- 猜測班級碼、邀請碼或家長登入連結。
- 惡意建立大量班級、學生或家長資料消耗資源。

最低限度應維持：

- 申請與登入頻率限制。
- IP 與帳號 rate limit。
- 圖片格式與大小驗證。
- Webhook 簽章驗證。
- 短效且不可預測的登入 token。
- 管理者停權與刪除能力。
- 異常流量告警。
- 禁止公開存取原始附件網址。

若發現濫用：

1. 先停用可疑帳號或限制操作。
2. 檢查近期貼文、圖片、Webhook 與登入紀錄。
3. 清理不當內容與過期附件。
4. 視情況封鎖來源 IP 或調整 rate limit。
5. 記錄處理結果。

## 上線前檢查清單

帳號與限制：

- 已確認帳號採申請審核制。
- 已確認免費帳號期限與未登入處理規則。
- 已確認 50 位學生、每位學生 3 位家長、每日 30 則訊息限制。

核心流程：

- 老師可登入。
- 老師可建立班級。
- 老師可建立家長邀請。
- 家長可綁定邀請。
- 老師可發布今日事項。
- 家長可查看今日事項。
- 家長可確認需要確認的事項。
- 老師可看到已讀與已確認數。

資料與安全：

- 圖片只能透過授權 API 讀取。
- 圖片到期後不可顯示。
- 圖片清理可手動執行。
- 日誌與 analytics 不記錄完整 token、學生姓名、家長姓名、訊息內容或圖片內容。
- Webhook payload 不包含聯絡簿內容或個人資料。

服務聲明：

- 已說明不保證永久營運。
- 已說明不保證 100% 可用。
- 已說明不可作為緊急通知管道。
- 已提醒重要資料自行備份。
- 已保留暫停帳號、刪除違規內容與終止服務的權利。

## 常見問題

### 家長說沒有收到通知

ClassHub 不是 App，不提供手機系統推播。請先請家長打開 ClassHub 家長頁並按重新整理。若使用 LINE OA，LINE 只作為選配通知入口，可能因 LINE 平台、網路或設定造成延遲。

### 家長看不到今日事項

檢查：

- 家長是否已完成綁定。
- 老師是否發布到正確班級。
- 學生是否仍為 active。
- 家長是否綁定到該學生。
- 家長頁是否使用正確 ClassHub ID。

### 圖片看不到

檢查：

- 圖片是否已超過保留時間。
- 家長是否有該學生的存取權。
- 圖片是否上傳成功。
- 老師或管理者是否已執行清理圖片。

### 今日發布失敗

檢查：

- 是否已選班級。
- 今日發布數是否已達 30 則。
- 是否已有學生與家長綁定。
- 圖片是否超過張數或大小限制。
- 網路或後端服務是否正常。

### 帳號到期後可以恢復資料嗎

不保證。免費帳號期滿後可以重新申請，但舊帳號資料不移轉。重要資料應由使用者自行備份。
