ClassHub 家長邀請手機流程

給老師、教練在手機上使用：建立家長邀請後，產生 QR Code 或邀請連結， 可用 LINE、Email、Facebook 或任何手機分享方式傳給家長。

1. 教師用手機登入

輸入 ClassHub ID 與密碼，登入後會看到班級狀態。

2. 選定或建立班級

教師至少需要一個班級。可在「班級」選擇既有班級，或直接建立新班級。

3. 建立家長邀請

在「連結與邀請」選班級。學生可選「新增學生」並輸入新學生姓名，也可選既有學生。 填家長姓名後，按「建立家長並產生邀請碼」。

  • 新學生 + 新家長：選班級，學生選「新增學生」，填學生與家長。
  • 舊有學生 + 新家長：選班級，學生選既有學生，只填新家長。
  • 同一學生多位家長：對同一位學生重複新增不同家長。

4. 產生 QR Code 並分享

建立家長邀請成功後，老師會看到家長邀請 QR Code、邀請連結、分享按鈕與複製連結按鈕。 若學生與家長已經存在於「既有連結」，可選該組「學生 / 家長」後按「重新產生邀請碼」。 若班級名單已透過 CSV 匯入，或班級內已建立多位學生與家長連結，老師可按「產生整班 QR Code」批次產生家長邀請卡片並列印。 戶外或手機情境不需要貼一大串文字。

家長收到後怎麼開

5. 家長用手機開啟邀請

家長點連結或掃 QR Code 後，手機瀏覽器會開啟 ClassHub 家長頁，並自動帶入 ClassHub ID 與邀請碼。 家長只要按「綁定家長」。

6. 家長完成綁定

綁定完成後，家長可進入家長頁查看今日事項與通知。

重點摘要

  • 「建立家長邀請」是主要入口：選班級、選新增或既有學生、填家長、產生邀請。
  • 「既有連結」只用來重新產生已存在綁定的邀請碼。
  • 下方「學生與家長」管理區只用來更新或刪除資料，不是邀請入口。
  • 舊有學生要新增家長時，在「建立家長邀請」選既有學生，再填新家長姓名。
  • 整班名單匯入後，可使用「產生整班 QR Code」批次產生家長邀請卡片。
  • 老師在手機上產生邀請後，可以直接讓家長掃 QR Code。
  • 遠端邀請可按「分享」，用 LINE、Email、Facebook 或任何手機 App 傳送。
  • 不支援分享的裝置，可用「複製連結」貼到通訊 App。
  • 家長點連結或掃 QR Code 後，會自動進家長頁並預填邀請碼。
  • 家長只需要按「綁定家長」，不需要手動輸入長邀請碼。
