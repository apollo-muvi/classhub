# ClassHub

> 免費申請使用的班級與社團聯絡服務，協助老師、教練與社團更簡單地與家長溝通。

目前服務版本：`0.2.0`

申請頁：<https://apollo-muvi.github.io/classhub/>

申請頁會導向 ClassHub Google Form，送出後進入審核流程。

> **想自己架嗎？** ClassHub 也提供[開源版本（OSS）](https://github.com/apollo-muvi/ossclasshub)，你可以自行下載、安裝在自己伺服器上，所有資料完全由你掌控。適合有資安考量、希望資料不假他人之手的使用者。

> **線上簡報**：[為什麼您需要 ClassHub？](https://apollo-muvi.github.io/classhub/presentation.html) — 自動播放，每 6 秒切換，也可手動操作。

ClassHub 是一個輕量級的班級與社團聯絡工具，協助使用者在同一個 Web 服務中處理兩種溝通模式：

- **班級模式**：正式聯絡簿流程，包含班級、學生、家長綁定、今日事項、確認、回覆與收件狀態。
- **群組模式**：不需要學生與家長綁定的短期分享流程。使用者建立群組、選定群組後產生公開連結；知道連結的人可在有效期限內查看，系統會累計閱讀次數。

它適合學校、補習班、安親班、家教老師、社團教練，以及任何需要簡單班級溝通系統的團隊。

ClassHub 是 RWD 網頁服務，可在手機、平板與電腦瀏覽器中使用，不需要安裝 App。ClassHub 不需要 AI 供應商、不產生 token 成本，也不綁定特定通訊平台。

## 目前核心功能

- 使用者登入後可切換「班級模式」與「群組模式」。
- 使用者可用 CSV 匯入 Google Sheet 匯出的班級名單，先預覽再同步。
- 匯入名單可建立班級、學生、家長電話與學生編號；系統自動產生家長分享連結與 QR Code。
- 使用者可產生整班家長 QR Code，並列印 QR Code 卡片。
- 使用者可在班級模式發布公告、作業、攜帶物品、活動、請假、繳費提醒或其他今日事項。
- 家長可透過手機瀏覽器查看今日事項、圖片、確認事項，並送出最多 200 字的簡短回覆。
- 使用者可看到每則貼文的收件人數、已查看數、已確認數、回覆數，並可開啟逐位收件人狀態明細。
- 使用者可刪除不再使用的班級；刪除前會先顯示影響摘要，並要求輸入班級名稱確認。
- 群組模式可建立與移除分享群組，建立短期分享並選擇 1、2 或 3 天有效。
- 短期分享不需要學生 / 家長綁定；知道連結的人可查看，公開頁每次開啟會讓閱讀紀錄加 1。

## 免費服務原則

ClassHub 的免費服務目標，是在固定且有限的系統資源下，盡可能提供穩定、簡單、安全的班級與社團聯絡工具。

因此，ClassHub 會優先維持核心流程穩定，而不是提供無限制的帳號、資料保存、客服支援或客製化功能。

為了讓更多實際教學場景可以使用 ClassHub，免費服務會採取明確的使用限制、帳號期限、資料保留期限與審核機制。這些限制是為了避免少數異常使用消耗過多資源，影響其他使用者的基本使用品質。

## 免費使用與帳號申請

ClassHub 目前提供免費申請使用。

為了維持服務品質、資料安全與公平使用，ClassHub 採申請制。帳號需經審核後開通，並不提供完全開放的即時註冊。

申請時僅收集必要資料，例如：

- 申請人稱呼
- Email
- 單位類型
- 使用場景簡述
- 補充說明
- 免費服務限制與使用提醒的同意確認

ClassHub 不會在申請階段要求提供學生名單、家長名單、家長電話、詳細地址、身分證明文件、預計班級數、預計學生 / 家長數，或 LINE OA 使用需求。

## 使用限制

ClassHub 免費方案會有明確的使用限制，包含但不限於：

- 每個帳號最多可管理 50 位學生
- 每位學生最多可綁定 3 位家長
- 每個帳號每天最多可發布 30 則訊息
- 每篇訊息最多可附加 3 張圖片
- 每則短期分享最多 3 張圖片，最長有效期限 3 天
- 單張圖片大小上限依系統設定限制
- 名單匯入支援 CSV 檔案，單檔最大 256 KB，最多 300 筆資料列；正式帳號有效學生總數仍受 50 位上限限制
- 教師上傳的圖片預設保留 24 小時
- 免費服務每日預定開放時間為台灣時間 06:00-22:00
- API 或 Webhook 呼叫頻率會受到限制

ClassHub 保留依系統資源、濫用風險與服務狀況調整限制的權利。

## 通知方式

ClassHub 是 Web-based 服務，不是原生手機 App。目前不提供 App Store / Google Play App，也不提供系統層級的手機推播通知。

ClassHub 的主要使用方式，是使用者在班級模式發布訊息後，家長透過 ClassHub 家長頁查看今日訊息與圖片。選配的 LINE OA 可作為輔助通知入口，完整內容仍以 ClassHub 網頁內顯示為準。

ClassHub 會盡力即時顯示與傳遞訊息，但瀏覽器、網路、裝置、LINE OA 或系統狀況可能造成延遲或無法送達。

進階整合如 API 或 Webhook 會受到呼叫頻率限制，且不作為一般使用者的主要通知方式。

## 第三方服務與 LINE OA

ClassHub 可視情況提供 LINE OA 等第三方通知整合功能，但這些功能屬於選配。

LINE 官方帳號、訊息額度、平台規則、第三方服務費用、設定維護與相關責任，皆不包含在 ClassHub 免費服務範圍內，並由使用者自行負責。

ClassHub 不保證 LINE OA 或其他第三方平台的訊息一定即時送達，也不負責第三方平台造成的延遲、中斷、費用、帳號限制或政策變更。

## 帳號有效期限與未登入處理

每個 ClassHub 免費帳號的使用期限最長為 6 個月。期滿後帳號與相關資料可能被停用或移除。

期滿後，使用者可以重新提出申請；但重新申請不代表一定會通過審核，且舊帳號資料不會移轉到新帳號。ClassHub 不提供舊帳號資料移轉、合併或代為匯入新帳號的服務。

為了維持服務資源與資料安全，ClassHub 會定期清理長時間未使用的帳號：

- 帳號連續 30 天未登入時，ClassHub 會盡力寄送 Email 通知。
- 通知後 10 天內仍未登入者，帳號將被停用。
- 帳號停用後 5 天內若未提出恢復申請或完成必要確認，ClassHub 可能移除該帳號與相關資料。

帳號與資料一旦移除，可能無法復原。重要資料請使用者自行備份。

ClassHub 會盡力寄送提醒通知，但 Email 可能因信箱設定、垃圾郵件過濾、地址錯誤或其他因素無法送達。未收到通知不代表帳號不會依上述規則停用或移除。

## 資料最小化原則

ClassHub 採取資料最小化設計：能不收集的資料就不收集，能使用稱呼的地方就不要求真實姓名。

使用者建立學生、家長或班級資料時，應避免輸入不必要的個人資料。學生與家長欄位可使用稱呼、代號或暱稱，不需要填寫真實姓名。

ClassHub 不會將學生姓名、家長姓名、訊息內容、圖片內容或完整 token 傳送到 Analytics。Webhook 事件也只傳送必要的事件 ID、分類、日期、狀態與數量，不包含聯絡簿內容或個人資料。

教師上傳的圖片預設保留 24 小時。過期後圖片會停止顯示，並由系統背景清理程序刪除。

圖片不會以公開原始檔案網址提供；前端只會取得受權限控管的 API 圖片路徑，系統會依登入身分與家長綁定關係檢查存取權限。

## 服務限制與使用提醒

ClassHub 目前以免費服務形式提供，並非具備正式 SLA 的商業保證服務。

ClassHub 免費服務每日預定開放時間為台灣時間 06:00-22:00。非服務時間內，系統可能暫停、進行維護、備份或資源調整，使用者可能無法登入、發布、查看訊息或接收通知。

使用 ClassHub 時，請理解並接受以下限制：

- 不保證永久營運
- 不保證 100% 可用
- 非每日服務時間內不保證可使用
- 不應作為緊急通知、即時救援或唯一正式通知管道
- 重要資料應由使用者自行備份
- 系統故障、網路異常、裝置設定或第三方平台狀況，可能造成訊息延遲或無法送達
- ClassHub 保留拒絕申請、限制使用、暫停帳號、刪除違規內容或終止服務的權利

ClassHub 會盡力即時顯示與傳遞訊息，但網路、裝置、第三方平台或系統狀況可能造成延遲。

## 安全與濫用防護

ClassHub 雖然目前提供免費申請使用，但免費不代表開放濫用。為了保護服務穩定、資料安全與真實教學使用者，ClassHub 會採取必要的安全與限制措施。

可能被限制或阻擋的行為包含：

- 大量註冊垃圾帳號
- 使用機器人建立班級或上傳圖片
- 將 ClassHub 作為免費圖床或檔案儲存服務
- 大量呼叫 API 或 Webhook
- 發送廣告、垃圾訊息或不當內容
- 猜測班級碼、邀請碼、家長登入連結或其他存取 token
- 惡意建立大量班級、學生或家長資料以消耗系統資源

ClassHub 會視需要採用帳號審核、rate limit、圖片限制、Webhook 簽章、短效 token、附件權限控管、異常流量告警，以及管理者停權或刪除功能。

## 支援範圍

ClassHub 免費服務不包含無限制客服、資料代工或客製化開發。

目前支援範圍包含：

- 操作文件
- 問題回報表單
- 重要錯誤修復
- 必要的安全與穩定性改善

目前不提供：

- 電話客服
- 即時客服
- 承諾回覆時間
- 資料代為輸入、整理或匯入
- 個別單位客製化功能
- 舊版瀏覽器或特殊裝置保證支援
- 因免費服務中斷、延遲或資料遺失所產生的補償

## 免費版設計原則

ClassHub 免費版不追求功能最多，而是優先確保核心流程穩定、清楚、安全。

免費版會優先維持下列核心流程：

- 管理者建立班級
- 使用者發布聯絡簿
- 家長安全登入
- 家長查看今日訊息
- 使用者建立群組並發送短期分享
- 圖片與資料到期清楚提示並自動清理

為了維持穩定性，ClassHub 可能限制或延後非核心功能，例如即時雙向 Google Sheet 同步、進階統計、客製化欄位、複雜權限設定、第三方整合或高頻 API / Webhook 使用。
